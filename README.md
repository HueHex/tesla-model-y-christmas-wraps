# Christmas wraps for the original Tesla Model Y

A collection of 13 Christmas designs for the on-screen Model Y in Tesla Paint Shop. Built for a 2021 Model Y using Tesla’s original Model Y template. The 2025+ Model Y versions have separate templates.

![Five designs showing the artwork on the hood, doors and hatch](previews/Christmas%20Collection%20Preview.jpg)

## Choose a wrap

Select a design name to open its uploadable PNG on GitHub, then choose **Download raw file**. For the whole collection, choose **Code → Download ZIP** on the repository home page and extract it. The `Wraps` folder contains all 13 PNGs.

## Apply it in Paint Shop

1. In Tesla app version 4.59.0 or later, open **Creations → Wrap → Upload** and choose a PNG from `Wraps`.
2. For USB transfer, copy up to 10 of your favorite PNGs into a folder named `Wraps` at the root of a supported USB drive. Tesla lists a limit of 10 wraps from the app and 10 from USB.
3. In the car, open **Toybox → Paint Shop → Wraps**. Select a design and rotate the vehicle to check each panel.

The included PNGs were checked for square dimensions, filenames and the 1 MB size limit. The JPGs are flat panel previews. Alignment on the in-car 3D model has not been verified.
